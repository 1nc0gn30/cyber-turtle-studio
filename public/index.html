📖 Grammar & Symbol Reference Guide

L-System Turtle Grammar Symbols:

  • F or G: Move forward drawing a line of step size.
  • f: Move forward without drawing (pen up move).
  • +: Turn right by branching angle $\theta$.
  • -: Turn left by branching angle $\theta$.
  • [: Push current turtle position, heading, and pen onto state stack.
  • ]: Pop and restore saved state from stack (branch return).
  • |: Turn 180° around.
  • < / >: Scale step size down/up.

Logo DSL Script Commands:

  • fd <dist> / bk <dist>: Forward / Backward distance.
  • lt <angle> / rt <angle>: Left / Right rotation in degrees.
  • pu / pd: Pen Up / Pen Down.
  • repeat <count> [ ... ]: Loop block (supports nesting).
  • color #hex / width <px>: Pen styling.
  • circle <radius> [extent]: Arc / Circle generator.

CNC G-Code Plotter Standards:

Generates standard RS-274 / ISO G-Code compatible with GRBL, Marlin, AxiDraw, EleksMaker, and Universal G-Code Sender.
